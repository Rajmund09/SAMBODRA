# SAMBODRA

SAMBODRA is a web project featuring "BANDHA — The Thread That Binds", a beautifully designed, highly textured web page with custom themes, styling, and interactive elements.

## Features
- **Region Explorer**: Interactively switch the active region to see its signature silk and dynamic background textures.
- **Product Showcase**: A swatch grid featuring 3D hover effects. Clicking a saree swatch opens a detailed full-screen modal.
- **Dynamic Interactions**: Toast notification system for capturing user actions like newsletter signups and upcoming feature links.
- **Responsive Design**: Carefully crafted breakpoints ensuring the site works smoothly on both desktop and mobile devices.

## Technologies Used
- HTML5
- CSS3 (Vanilla)
- JavaScript (Vanilla)
- GSAP (GreenSock Animation Platform) for smooth animations and scroll reveals

## Getting Started
Simply open `bandha.html` in any modern web browser to view the project. No build steps or server are required!
